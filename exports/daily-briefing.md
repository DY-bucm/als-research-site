1. **胸腺是肌萎缩侧索硬化病理生理学的靶标和维持者**
   - 临床试验 / 动物/细胞实验 / high
   - ALS小鼠晚期出现胸腺萎缩、髓质胸腺上皮细胞丢失、Treg发育和抑制功能受损，Foxp3+细胞异常定位于皮质，提示胸腺是ALS免疫失调的靶器官。
   - https://pubmed.ncbi.nlm.nih.gov/42756835/
2. **弥合肌萎缩侧索硬化症临床试验的可信度差距**
   - 临床试验 / 专家观点/评论文章 / high
   - ALS早期和中期试验数据常被用于宣称临床获益，但未能转化为3期成功；作者认为这源于“临床试验工业复合体”的扭曲激励和多种科学推理谬误。
   - https://pubmed.ncbi.nlm.nih.gov/42685299/
3. **选择性靶向少突胶质细胞GPR17受体可改善雌性SOD1 G93A小鼠的髓鞘完整性和运动功能**
   - 临床试验 / 动物/细胞实验 / high
   - GPR17在人类ALS脊髓中标记病理性未成熟少突胶质细胞；脑渗透性GPR17激动剂长期治疗可延长雌性SOD1 G93A小鼠生存期、改善运动功能并保护髓鞘和运动神经元，雄性小鼠获益不明显。
   - https://pubmed.ncbi.nlm.nih.gov/42674126/
4. **从携带TARDBP突变的iPSC来源运动神经元中我们能学到什么关于ALS病理生理学的知识：一项系统综述**
   - 临床试验 / 观察性临床研究 / high
   - TARDBP突变iPSC来源运动神经元模型在重现ALS病理方面存在研究间差异，技术参数如分化方案、细胞年龄和纯度、定量方法显著影响表型，且非细胞自主机制可能参与TDP-43-ALS病理生理学。
   - https://pubmed.ncbi.nlm.nih.gov/42764383/
5. **TBK1过表达减少ALS/FTD的P497S UBQLN2小鼠模型中的神经元丢失**
   - 临床试验 / 动物/细胞实验 / high
   - 在P497S UBQLN2 ALS/FTD小鼠模型中，TBK1过表达显著减少脑和脊髓的神经退行性变；UBQLN2与TBK1直接结合，P497S突变降低该结合，且UBQLN2缺失使TBK1不稳定。
   - https://pubmed.ncbi.nlm.nih.gov/42763025/
6. **细胞衰老是肌萎缩侧索硬化TDP-43 Q331K小鼠的早期特征及治疗靶点**
   - 临床试验 / 动物/细胞实验 / high
   - 细胞衰老标志物在ALS小鼠运动皮层和脊髓中早期出现；达沙替尼联合槲皮素治疗可改善运动行为、神经肌肉功能、运动皮层兴奋性，降低血浆神经丝轻链，并减少小胶质细胞TDP-43负荷和衰老标志物。
   - https://pubmed.ncbi.nlm.nih.gov/42759848/
