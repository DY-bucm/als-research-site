2. **弥合肌萎缩侧索硬化症临床试验的可信度差距**
   - 临床试验 / 专家观点/评论 / high

3. **成人起病非5q型脊髓性肌萎缩症患者中的LRP12 CGG重复扩增**
   - 临床试验 / 观察性临床研究 / high
   - 在8个遗传学未确诊的成人起病非5q型SMA家系中，6个（75%）携带LRP12 CGG重复扩增，患者表现为缓慢进展的纯下运动神经元无力，且该扩增在ALS和对照中均罕见。
   - https://pubmed.ncbi.nlm.nih.gov/42788121/
4. **人工智能在神经肌肉疾病中的应用：数据稀缺领域的机遇**
   - 临床试验 / 叙述性综述 / high
   - AI在NMD领域已取得诊断、监测和预后方面的进展，ALS和杜氏肌营养不良症研究最集中；AI驱动的ALS生存模型已在14个欧洲中心验证，ML蛋白质组学已识别ALS诊断组合；但多数模型缺乏外部验证和临床实施。
   - https://pubmed.ncbi.nlm.nih.gov/42675240/
5. **选择性靶向少突胶质细胞GPR17受体改善雌性SOD1 G93A小鼠的髓鞘完整性和运动功能**
   - 临床试验 / 动物/细胞实验 / high
   - GPR17在人类ALS脊髓中标记病理性未成熟少突胶质细胞；脑渗透性GPR17激动剂可恢复雌性SOD1 G93A小鼠少突胶质细胞成熟、髓鞘完整性和运动功能并延长生存期，雄性小鼠无显著获益。
   - https://pubmed.ncbi.nlm.nih.gov/42674126/
6. **LRSAM1作为一种E3泛素连接酶在肌萎缩侧索硬化中调控TDP-43蛋白稳态**
   - 临床试验 / 观察性临床研究结合体外细胞模型机制研究 / high

   - https://pubmed.ncbi.nlm.nih.gov/42803299/
