1. **胸腺是肌萎缩侧索硬化病理生理学的靶标和维持者**

   - 临床试验 / 专家评论/方法学述评 / high

3. **人工智能在神经肌肉疾病中的应用：数据稀缺领域的机遇**
   - 临床试验 / 叙述性综述 / high
   - AI在ALS中已有生存模型多中心验证和蛋白质组学诊断组合识别等进展，但绝大多数NMD的AI模型仍停留在单中心开发和内部验证阶段，缺乏外部验证与临床实施；ALS和杜氏肌营养不良症研究集中，其他NMD亚型几乎空白。
   - https://pubmed.ncbi.nlm.nih.gov/42675240/
4. **选择性靶向少突胶质细胞GPR17受体可改善雌性SOD1 G93A小鼠的髓鞘完整性和运动功能**
   - 临床试验 / 动物/细胞实验 / high
   - GPR17在人类ALS脊髓中上调并标记病理性未成熟少突胶质细胞；脑渗透性GPR17激动剂可延长雌性SOD1 G93A小鼠生存期、改善运动功能并保护髓鞘和运动神经元，雄性小鼠无显著获益。
   - https://pubmed.ncbi.nlm.nih.gov/42674126/
5. **内在无序蛋白与液-液相分离：分子语法、凝聚体生理学及疾病相关相变**
   - 临床试验 / 综述/荟萃分析 / high
   - TDP-43和FUS等ALS相关蛋白的异常液-固相变是神经退行性疾病的趋同病理机制，凝聚体可作为可成药靶点，通过溶解剂、诱导剂、定位剂和形态调节剂四类策略干预。
   - https://pubmed.ncbi.nlm.nih.gov/42790799/
6. **利用同源同一性解析神经退行性疾病中的不完全外显并推进基因发现**
   - 遗传 / 观察性临床研究 / high
   - IBD分析在ALS-FTD队列中识别出大量此前未识别的亲缘关系，其中5.5%的ALS和15.9%的FTD“散发性”患者与其他患者存在遗传关联，表明不完全外显掩盖了相当比例的遗传性疾病；IBD还成功构建了73个新家系并缩小了候选区域。
   - https://pubmed.ncbi.nlm.nih.gov/42789481/
