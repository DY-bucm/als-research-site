1. **胸腺是肌萎缩侧索硬化病理生理学的靶标和维持者**
   - 临床试验 / 动物/细胞实验 / high

3. **选择性靶向少突胶质细胞GPR17受体改善雌性SOD1 G93A小鼠的髓鞘完整性和运动功能**
   - 临床试验 / 动物/细胞实验 / high
   - GPR17在人类ALS脊髓中上调并标记病理性未成熟少突胶质细胞；脑渗透性GPR17激动剂长期治疗可延长雌性SOD1 G93A小鼠生存期、改善运动功能并保护髓鞘和运动神经元，雄性小鼠无显著获益。
   - https://pubmed.ncbi.nlm.nih.gov/42674126/
4. **线粒体酸5通过增强线粒体功能缓解肌萎缩侧索硬化表型**
   - 临床试验 / 临床前研究（果蝇模型、患者来源成纤维细胞及iPSC来源运动神经元） / high
   - 线粒体靶向化合物MA-5可改善ALS模型运动功能、恢复ATP产生、增强线粒体运动能力，并可能通过下调甘油磷酸穿梭减少线粒体活性氧；C7orf31被鉴定为潜在疗效监测和亚型诊断标志物。
   - https://pubmed.ncbi.nlm.nih.gov/42770300/
5. **趋同的TBK1功能缺失驱动gasdermin E依赖性细胞焦亡及跨ALS基因型的运动神经元变性**
   - 临床试验 / 观察性临床研究（含患者来源细胞及动物模型机制验证） / high
   - 不同ALS基因型患者来源运动神经元均表现TBK1活性降低、caspase-8/7-GSDME细胞焦亡激活及TDP-43病理，TBK1功能缺失被鉴定为共同上游驱动因素。
